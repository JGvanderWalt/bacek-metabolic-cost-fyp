# Aggregate experimental results

These files contain procedure-level performance summaries, selected comparison metrics and uncertainty intervals. They were copied directly from retained experiment evidence; the numerical values have not been edited.

The E1–E5 file prefixes indicate the experiment supported. See the notebooks for the implemented procedures and the main README for the primary comparison.

Only aggregate evidence is distributed here. Raw gait data, participant-linked waveforms, individual-trial predictions, original hash-locked result ZIPs, and fixed assignment records are not included. **A fresh full rerun or trial-level numerical reconstruction is not possible from these CSVs alone.**

E3.4 and E5.3 results are secondary exploratory-informed analyses. The associated original run summaries recorded local checks, with subsequent full independent N3 verification still requiring separate supporting evidence; do not interpret the aggregate tables alone as final N3 sign-off.
