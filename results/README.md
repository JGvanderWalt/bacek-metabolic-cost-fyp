# Aggregate experimental results

These CSVs summarise procedure-level performance, model comparisons and uncertainty intervals from the retained experiment records.

The E1–E5 file prefixes indicate the experiment supported. See the notebooks for the implemented procedures and the main README for the primary comparison.

The files support aggregate result inspection. Trial-level recalculation also requires the retained prediction ledgers and fixed manifests; see the [data-access guide](../data/DATA_ACCESS.md).

E3.4 and E5.3 are secondary, exploratory-informed analyses with completed local checks; independent metric-reconstruction verification (N3) remains outstanding.
