# Machine Learning-Based Estimation of Walking Metabolic Cost

Final-year Computer and Electronic Engineering project investigating the feasibility of estimating steady-state walking metabolic power from gait kinematics using machine learning.

## Dataset

The investigation uses the publicly available Baček gait dataset, containing optical gait kinematics and metabolic measurements from treadmill walking experiments.

Original dataset: [University of Melbourne Figshare](https://figshare.unimelb.edu.au/articles/dataset/24270064)
